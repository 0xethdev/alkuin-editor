The file is the variable outline font. It is not the color bitmap font.
It covers U+1F30A. A PDF that uses it draws the default instance.

These are the full fonts. Export does not ship a one-glyph subset.
A character in none of Times, Droid Sans Fallback, and Noto Emoji stops the PDF.
